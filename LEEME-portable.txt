===========================================
  SCRUM COCKPIT  -  Version portable
===========================================

Que es:
  App de escritorio que muestra en una sola pantalla la actividad de uno o
  varios proyectos de Azure DevOps:
    - Feed de actividad en vivo ("Fulano paso la US 28173 a Mengano")
    - Board con todas las US / BUG / TASK en columnas
    - Metricas (carga por persona, estados, puntos y nivel de compromiso)
    - Evolutivo (tendencias por sprint)
    - QA (quien cerro cada item, test cases por tester, puntos de regresion)
    - Filtros y busqueda


-------------------------------------------
  COMO USARLA
-------------------------------------------

1) IMPORTANTE: antes de abrir la app, configura el token (PAT) en una
   variable de entorno (ver mas abajo). Por seguridad, la app NO guarda el
   token y SOLO lo lee de ahi.

2) Doble clic en  ScrumCockpit.exe
   (No necesita instalacion. Se puede correr desde una carpeta, un
    pendrive, el escritorio, donde sea.)

3) La primera vez te pide cargar un proyecto:
     - Nombre       : como lo vas a ver en el selector (ej. "Mobile")
     - Organizacion : el nombre que aparece en dev.azure.com/TU-ORG
     - Proyecto     : el nombre exacto del proyecto
     - Equipo       : (opcional, solo para metricas de sprint)
     - Variable     : cual de tus variables de entorno tiene el token de
                      ESTE proyecto (por defecto AZURE_DEVOPS_EXT_PAT)

   Y en "Ajustes generales", para todos los proyectos:
     - Intervalo    : cada cuantos segundos busca cambios (default 30)
     - Ultimos dias : ventana de fecha. Solo trae actividad de los ultimos
                      N dias (default 60 = ~2 meses), para no arrastrar
                      sprints/versiones viejas. Subilo si necesitas mas.
     - Puntos por talle : como se convierte el campo "Estimacion"
                      (XS/S/M/L/XL) a puntos.

4) Apreta "Probar conexion" y, si dice OK, "Guardar proyecto".


-------------------------------------------
  VARIOS PROYECTOS A LA VEZ
-------------------------------------------

Desde el selector de arriba a la derecha podes agregar mas proyectos y
elegir cuales ver:

  - Con UNO tildado funciona como un switcher: mismas pestanas, otro
    proyecto.
  - Con VARIOS tildados se ven todos juntos en una vista fusionada, y cada
    item lleva un badge de color con el proyecto del que viene.

Cada proyecto puede usar SU PROPIO token, asi que podes mezclar
organizaciones distintas. Solo tenes que definir una variable de entorno
por token (ver abajo) e indicar cual usa cada uno.


-------------------------------------------
  EL TOKEN (PAT) DE AZURE DEVOPS
-------------------------------------------

Se genera una sola vez en Azure DevOps:
   User settings (arriba a la derecha) -> Personal access tokens -> New Token
   Permisos minimos:  Work Items (Read)  y  Project and Team (Read)

Por seguridad, el token se usa SOLO por variable de entorno (nunca se guarda
en disco ni se pega en la app). Abri una consola (cmd) y corre:

    setx AZURE_DEVOPS_EXT_PAT "tu-token-aca"

Si tenes varios proyectos con tokens distintos, defini una variable por
token. El nombre tiene que estar en MAYUSCULAS y terminar en PAT o TOKEN:

    setx SCRUM_COCKPIT_PAT_MOBILE "token-de-la-organizacion-A"
    setx SCRUM_COCKPIT_PAT_WEB    "token-de-la-organizacion-B"

Cerra y volve a abrir la app. Va a tomar los tokens sola.


-------------------------------------------
  COMO SE CUENTAN LOS PUNTOS
-------------------------------------------

Cada item aporta SUS Story Points. Si ese campo esta vacio, se usa el campo
"Estimacion" (talle XS/S/M/L/XL) convertido con la tabla de Ajustes
generales. Nunca se cuentan los dos campos para el mismo item, asi que no
hay doble conteo.

Si en tus items aparece un talle que no esta en la tabla, Configuracion te
lo marca en amarillo: hasta que le pongas un valor, esas US suman 0.


-------------------------------------------
  LA PESTANA QA
-------------------------------------------

Se trabaja sobre UN sprint por vez (selector arriba a la izquierda):

  - Items cerrados: agrupados por quien los cerro (campo "Closed By").
    Ojo: Azure DevOps solo completa ese campo en el estado Closed.
  - Test Cases sin tag "Regresion": cuantos tiene asignados cada tester
    en ese sprint.
  - Regresion: suma los puntos de los Test Cases que tengan el tag
    "Regresion" MAS el tag del sprint (ej. "5.26.05"). El tag se completa
    solo con el nombre del sprint, pero se puede corregir a mano si tu
    equipo etiqueta distinto.

Si faltan test cases de regresion, suele ser porque quedaron fuera de la
ventana de "Ultimos dias": subila y volve a mirar.


-------------------------------------------
  REQUISITOS
-------------------------------------------

  - Windows 10 u 11 (64 bits).
  - Microsoft Edge WebView2: viene incluido en Windows 11 y en casi todos
    los Windows 10 actualizados. Si la ventana de la app aparece en blanco,
    instala el "Evergreen WebView2 Runtime" (gratis, de Microsoft):
        https://developer.microsoft.com/microsoft-edge/webview2/


-------------------------------------------
  NOTAS
-------------------------------------------

  - Los tokens NUNCA se guardan: se leen solo de las variables de entorno.
    La configuracion (proyectos, org, ajustes) se guarda SOLO en esta PC
    (en la carpeta del usuario, AppData). No se manda nada a ningun
    servidor externo: la app habla directo con Azure DevOps.

  - Para cambiar la configuracion mas tarde: boton de engranaje (arriba a
    la derecha) dentro de la app, o "Agregar / administrar proyectos" en el
    selector de proyectos.
